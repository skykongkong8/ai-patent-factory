# 팥콩 팩토리 · 에이전트 활동 화면

이 프로젝트에서 사용하는 Codex·Claude Code 세션을 팥콩이 움직이는 공장으로
표시하는 선택 기능입니다. 기존 Python CLI와 별도로 실행합니다.

## 시작과 종료

Bun 1.1 이상이 필요합니다. 저장소 루트에서:

```bash
cd visualization
bun install --frozen-lockfile
bun start
```

브라우저에서 **http://127.0.0.1:4445**를 엽니다. 이 프로젝트 폴더나 그 하위
폴더에서 Codex 또는 Claude Code를 사용하면 세션이 나타납니다. UI를 켜기 전
최근 3시간 안에 갱신된 로그도 탐색하며, 오래된 세션이 재개되면 다시 표시합니다.
`Ctrl+C`로 서버와 화면 개발 서버를 함께 종료합니다.

실제 세션을 읽지 않고 둘러보려면 `bun start` 대신 다음 명령을 사용합니다.

```bash
bun run demo
```

데모는 임시 폴더에 공개 합성 Codex·Claude·하위 에이전트 로그를 만들고,
종료 시 해당 임시 폴더를 정리합니다. 데모 명령이나 도구는 실제 실행하지 않습니다.

## 화면 읽기

| 관찰한 활동 | 팥콩이 방문하는 방 |
| --- | --- |
| 읽기·검색 | 자료실 |
| 작성·편집 | 작업장 |
| 사고·계획 | 설계실 |
| 명령·테스트 | 실행실 |
| 오류 수정 | 정비실 |
| 검토·위임 | 검토실 |
| Git 작업 | 기록실 |
| 대기 | 휴게실 |

팥콩이나 세션 목록을 누르면 현재 요청·응답·명령·파일 경로·컨텍스트·스킬·플러그인과
하위 에이전트를 볼 수 있습니다. 지원하는 로그 필드에 한해서 표시하며, 컨텍스트
추정치는 원본의 추정/설정 출처를 함께 보여줍니다. 게이지는 공정 진행률이 아닙니다.
대기·종료는 로그 활동과 시간으로 추정하는 세션 상태입니다. 발명 공정의 완료,
검토 결과나 게이트 승인 여부는 이 화면에서 판정하지 않습니다.

지도 버튼은 새 탭에서 편집기를 엽니다. 지형과 작업실 배치, 장식, 팥콩 크기를
수정하고 슬롯에 저장할 수 있습니다. 지도 설정만 `server/data/maps/slot-*.json`과
`active-slot.json`에 저장되며 Git에서 제외됩니다. 기본 공장 지도는 함께 배포합니다.

## 관찰 범위와 데이터

- 프로젝트 루트는 설치된 `visualization/`의 부모에서 자동 결정합니다. 다른
  체크아웃·형제 폴더는 제외합니다. 실행은 관찰할 체크아웃에서 시작하세요.
- Codex의 초기 `session_meta.cwd`, Claude 로그의 초기 `cwd`와 확인된 부모 관계로
  서버에서 세션을 필터링합니다. 도구가 일시적으로 다른 폴더에서 실행되어도
  세션의 소속은 바뀌지 않습니다. 소속 불명 세션과 부모가 확인되지 않은 하위
  에이전트는 표시하지 않습니다.
- 기본 로그 위치는 `~/.codex/sessions/`와 `~/.claude*/projects/`입니다. 별도 설치는
  `PATKONG_CODEX_ROOT=/path/to/.codex` 또는 `PATKONG_CLAUDE_DIRS=/path/to/.claude`
  로 지정할 수 있습니다. 여러 Claude 디렉터리는 운영체제 경로 구분자(`:` on Linux)로
  구분합니다. 로그 디렉터리를 지정해도 프로젝트 필터는 유지됩니다.
- `documents/`, `workspace/`, Python DB·불변 export·`.env`를 열지 않습니다. 세션
  로그에 이미 있는 프롬프트·응답·파일 경로·명령을 로컬 브라우저에 표시합니다.
- API와 UI는 `127.0.0.1`에 바인딩합니다. LAN 모드와 원격 서버 URL 설정은
  지원하지 않습니다. 브라우저 Origin 검사도 HTTP와 WebSocket에 적용합니다.
- 대화·활동 피드는 메모리에서만 유지합니다. AI 검토용 복사·다운로드, 원격 이미지
  렌더링, 외부 폰트 로딩은 제공하지 않습니다. 로컬 브라우저 표시가 외부 공유나
  호스팅 모델 전송을 승인하지는 않습니다.
- Claude 전역 설정에 hook을 설치하지 않습니다. UI에서 공정 실행·승인·보고서
  공유를 수행하지 않습니다. Python CLI와 기존 단계별 요청 규칙을 사용하세요.

포트가 사용 중이면 `PORT=4454 CLIENT_PORT=4455 bun start`로 두 포트를 함께
변경할 수 있습니다. 이 경우 화면은 http://127.0.0.1:4455 입니다.

빈 화면에서는 이 체크아웃 안에서 세션을 시작하고 최대 3초의 수집 주기를
기다리세요. 연결 끊김 메시지는 `bun start` 실행과 포트 충돌 여부를 확인하세요.
로그 형식에 따라 제공되지 않는 활동·컨텍스트 필드가 있을 수 있습니다.

## 개발과 검증

```bash
bun test
bun run typecheck
bun run build
bun run check:assets
```

테스트와 데모는 합성 로그만 사용합니다. 실제 개인 로그를 테스트 자료나 이슈에
첨부하지 마세요. Python 검사 명령은 저장소 루트의 AGENTS.md를 따릅니다.

`bun run assets:generate`는 기존 공개 팥콩 드로잉 코드를 재사용해 투명 스프라이트,
작업실 PNG와 청사진 바닥을 재생성합니다. CPython 표준 라이브러리만 사용합니다.

원본과 수정 범위, 에셋 출처는 [UPSTREAM.md](UPSTREAM.md)를 참고하세요.
